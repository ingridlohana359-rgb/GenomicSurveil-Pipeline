# GenomicSurveil-Pipeline 

Pipeline modular multi-linguagem desenvolvido para automação de análises genômicas, combinando alta performance em C++, automação robusta em Bash e análise estatística em Python.

##  Stack Tecnológica
- **Bash:** Orquestração do pipeline e controle de fluxo.
- **C++:** Módulo compilado de alta performance para parsing e filtragem de arquivos de sequências biológicas (FASTA).
- **Python (Pandas):** Processamento estatístico e consolidação de relatórios de vigilância genômica.

## Como Executar
Certifique-se de ter um compilador C++ (`g++`) e Python 3 instalados no seu ambiente Linux/Ubuntu.
